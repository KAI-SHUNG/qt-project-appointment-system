## 一、数据层（src/）

### src/hospital.h / .cpp —— Hospital 类补全
把原来空壳的增删查与文件读写全部实现：

| 成员 | 签名 | 行为/规则 |
|---|---|---|
| `addDoctor` | `void (const Doctor&)` | 编号重复 → 抛 `std::invalid_argument` |
| `removeDoctor` | `bool (const QString&)` | 按编号删除并**级联删除**该医生全部预约 |
| `findDoctor` | `Doctor* (const QString&)` | 按编号查找，未找到返回 `nullptr` |
| `addAppointment` | `void (const Appointment&)` | 依次校验：医生存在 / 预约号唯一 / **身份证号不重复预约** / 时段在该医生排班中 / 预约数 < 时段容量（满号拒绝）→ 违例抛异常 |
| `removeAppointment` | `bool (const QString&)` | 按预约号删除 |
| `findAppointment` | `Appointment* (const QString&)` | 按预约号查找 |
| `countAppointments` | `int (doctorId, QDate, Timeslot)` | 某医生某日某时段已约数（供满号判断与 UI 显示余号） |
| `hasPatientAppointment` | `bool (patientId)` | 该身份证是否已存在预约（防重复） |
| `load` | `bool` | 有文件则读，缺文件按空处理；先医生后预约 |
| `save` | `bool` | 依次写医生、预约 |
| `getDoctors / getAppointments` | `const QList<...>&` | 只读访问容器 |

内部私有 I/O：`loadDoctors/loadAppointments/saveDoctors/saveAppointments`。修正点：

- 医生文件的 `性别/星期` 改为显式 `qint32` 序列化（原来会编译不过/不稳定），与预约文件一致；
- `loadAppointments` 遇到引用缺失医生的脏数据 → **跳过该条**，不再崩溃；
- 构造函数只在“未显式给路径”时才去建默认 `data/` 目录，避免测试污染磁盘。

### 失败机制约定
规则违规用**抛异常**（与 `Doctor::addTimeslot`、`Appointment` 构造一致），UI 层 `try/catch` 后弹中文提示。

### test/test_hospital.cpp（新增）
沿用 assert+qDebug 风格，`testHospital()` 聚合 5 组：重复编号、级联删除、预约规则（医生不存在/不在排班/满号/身份证重复/预约号重复+退号）、save→load 往返、缺文件加载。

### test/main_test.cpp（改动）
`#include "test/test_*.cpp"` 改为**前置声明**，避免与独立编译产生多重定义；入口新增 `testHospital()`。
